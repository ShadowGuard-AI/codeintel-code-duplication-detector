codeintel-code-duplication-detector

The Plate Store. A command line detector that hashes every window of lines in a Python codebase exactly as written and reports each later copy against the first plate it matches.

The repository main.py
Exact windowsWindows of exactly the -m line count, hashed with SHA-256 as read
First sighting keptEach later copy is reported as a pair against the first occurrence
The report-r names the report file, duplication_report.txt by default
Whole componentsExclusions match whole path components, never substrings

Usage

python3 main.py PATH [-m LINES] [-r REPORT] [-e NAME ...]

The README never names the positional in its usage or parameter text; the first argument is the file or directory to search. Only .py files are read.

OptionWhat it does
pathThe file or directory to search; never named in the README text.
-m LINESThe window size in lines, default 5. A window shorter than the file's remaining lines is never taken.
-r REPORTWhere the duplication report is written, duplication_report.txt by default.
-e NAMENames to exclude. A name matches a whole path component only: excluding venv leaves myvenv in the search.

What counts as a copy

  • The hash is taken over the window exactly as written, whitespace and comments included. A second copy of the same code with different spacing or a changed comment never matches the first. That is the rule of the store, and it is deliberate.
  • Files that cannot be read are named in the log and the report, the line saying nothing was found is withheld, and the run exits 1 while still covering every file it could read.

Requirements

Python's standard library only. The requirements.txt file is a comment stating exactly that.
